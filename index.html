GRADUATION CASE STUDY ENTERPRISE LAB

OPNsense NGFW & Site-to-Site IPsec VPN Deployment

1. Problem Statement: Securing multi-site enterprise communication against eavesdropping and unauthorized network intrusions without compromising performance.
2. Network Architecture: Dual-site firewall topology backed by OPNsense NGFW, integrating IPSec VPN gateways and an inline Suricata IDS/IPS engine.
3. Implementation Details: Configured IKEv2 IPsec tunnels with AES-256 encryption, DNS blocklists, granular firewall rulesets, and active signature inspection.
4. Verification & Result: Validated tunnel integrity via Kali Linux & Nmap scans; successfully detected and automatically blocked simulated threat traffic in real time.

RESEARCH STUDY SIMULATION

4G vs 5G Network Performance Modeling

1. Research Objective: Evaluating structural bottlenecks and latency scaling of legacy 4G LTE networks versus 5G New Radio (NR) under ultra-dense user scenarios.
2. Simulation Environment: Discrete-event network simulation built inside OMNeT++ with Simu5G framework to mirror real-world telecom traffic.
3. Performance Benchmarking: Measured end-to-end latency, packet loss, and throughput under escalating User Equipment (UE) load profiles.
4. Outcome Metrics: Demonstrated 5G NR latency drop from 0.9ms to 0.006ms and throughput scaling from 694.8 Mbps to 1.3 Gbps.
